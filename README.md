## Quick Start

Requires [Julia](https://julialang.org/install/) 1.12 or later. Paste the following into the Julia REPL or a notebook cell:

```julia
import Pkg; Pkg.add(url="https://github.com/ohno/MyPkg99.jl.git")
import MyPkg99; MyPkg99.hello()  # returns "Hello, World!"
```
